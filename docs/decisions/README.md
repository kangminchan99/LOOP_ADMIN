# 기술 결정 기록

되돌리기 어렵거나 여러 기능에 영향을 주는 기술 선택의 배경과 결과를 기록한다.

## 기록해야 하는 결정

- 주요 프레임워크 선택
- 인증 및 권한 방식
- 외부 서비스 도입
- 중요한 아키텍처 경계
- 공통 라이브러리와 데이터 형식
- 기존 원칙의 예외

## 파일 이름

```txt
YYYY-MM-DD-short-title.md
```

예시:

```txt
2026-08-06-use-nextjs-admin.md
```

## 작성 양식

```md
# 결정 제목

## 상태

제안됨 | 승인됨 | 대체됨

## 배경

어떤 문제와 제약이 있었는가?

## 결정

무엇을 선택했는가?

## 대안

검토했지만 선택하지 않은 대안은 무엇인가?

## 결과

장점, 비용, 위험, 후속 작업은 무엇인가?
```
